# Two Little Stars
Books for my daughters. Create themed, branching bedtime stories, customize the children's names and ages, and save favourites to read again.

Includes 18 themes and Surprise Me. Stories use clear, varied read-aloud language with dialogue and gentle puzzles. Model discovery is cached in memory for ten minutes, and subsequent chapters try the last successful model first. This reduces repeated API requests; generation speed still depends on Gemini availability.

Run the focused regression tests without an API key:

```sh
node --test tests/story.test.cjs
```
